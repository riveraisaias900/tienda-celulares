Para el Autónomo 1 se creó el esquema de cómo será el sistema de Gestión
venta de celulares. Estos gestionaran una tienda de dispositivos móviles que
en su stock tendrán 3 marcas elegibles: Apple, Samsung, Xiaomi 
este sistema permitirá la consulta de los dispositivos y recomendaciones de compra 
según el uso que el usuario le quiera destinar al teléfono.

Módulos disponibles

-Catálogo: Permite la consulta de marcas disponibles.

-Recomendaciones: Sugerencias de dispositivos según el uso que se planea dar.

-Administración: Registra, modifica o elimina los productos en stock.

-Ventas: Proceso final en la compra basada en "carrito" donde se suma el valor total y se confirma la compra.

Como ejecutar?
Para la ejecución del programa se debe usar go run. 
y para comprobar la compilación: go build ./...
